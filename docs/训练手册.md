# YOLO 训练手册（结合本项目）

> 只讲这个项目要用的部分。看完你应该能自己：体检数据 → 训练 → 判断好坏 → 推理。

## 1. 训练到底在干什么

三句话：

1. 模型对每张图输出一堆框：`(位置, 类别, 置信度)`。
2. 训练就是反复喂「图片 + 正确标注」，把预测和标注的差距（loss）算出来，反推参数往哪改。
3. **它不学规则，只学统计规律**。所以数据有多少、有多干净，直接决定上限——这也解释了为什么我们卡在数据量，而不是卡在调参。

## 2. 数据长什么样

```
dataset_school/
├── data.yaml
├── images/
│   ├── train/  039f0796-A_013.jpg ...
│   └── val/    f1ac407c-A_016.jpg ...
└── labels/
    ├── train/  039f0796-A_013.txt ...
    └── val/    f1ac407c-A_016.txt ...
```

**图片和标注必须同名**（只差扩展名）。

每个 `.txt` 每行一个框：

```
类别 中心x 中心y 宽 高        ← 全部是 0~1 的归一化值
0 0.503027 0.133687 0.130248 0.060212
```

换算：`中心x = (左上x + 右下x) / 2 / 图宽`，其余同理。

`data.yaml`：

```yaml
path: D:/bick/dataset_school
train: images/train
val: images/val

nc: 2                              # 类别数
names: ['bicycle', 'parking_area'] # 类别名，顺序 = 类别 id
```

**空 txt 是合法的**，表示"这张图没有目标"，会被当成负样本学习——海报、影子这类负样本就靠它。

## 4. 一条训练命令

```bat
set PYTHONPATH=D:\bick\yolo-lib
set YOLO_CONFIG_DIR=D:\bick\relabel\cfg

C:\Users\26803\miniconda3\envs\sam2\python.exe relabel\train.py ^
   --data dataset_school\data.yaml ^
   --weights relabel\weights\yolo11s.pt ^
   --imgsz 1280 --epochs 150 --batch 8 --lr0 0.002 --workers 0 --amp --name school_v4
```

每个参数在干什么：

| 参数 | 含义 | 本项目的取值理由 |
|---|---|---|
| `--data` | 数据集配置文件 | 指向 `data.yaml` |
| `--weights` | 从哪个权重开始 | `yolo11s.pt`=COCO 预训练，**不要从零开始**（17 张图从零训必废） |
| `--imgsz` | 输入分辨率 | 1280：你们的车在 3072 宽图里只占 200px 左右，640 会糊 |
| `--epochs` | 最多训多少轮 | 150，配合 early stop 自动停 |
| `--batch` | 一次看几张 | 8（12 GB 显存下 1280 的安全值） |
| `--lr0` | 初始学习率 | **0.002**，默认 0.01 在我们的数据上第 30 轮就崩 |
| `--workers` | 数据加载线程 | 0：本机沙箱下多进程会报错，图少影响不大 |
| `--amp` | 混合精度 | 开：不开会慢 10 倍 |
| `--name` | 输出目录名 | 结果在 `runs/school_v4/` |

## 5. 训练时屏幕上的数字

```
Epoch  GPU_mem  box_loss  cls_loss  dfl_loss  Instances  Size
  1/150   8.36G    1.87      3.695     1.752       137     1280
```

| 列 | 含义 | 怎么看 |
|---|---|---|
| `box_loss` | 边框位置误差 | 应该缓慢下降；突然跳到 3.5+ 说明要发散 |
| `cls_loss` | 分类误差 | 同上；跳到几百上千 = 出问题了 |
| `dfl_loss` | 边框细化误差 | 一般跟着 box_loss 走 |

每轮末尾还有：

```
Class  Images  Instances  Box(P  R  mAP50  mAP50-95)
  all      3         34   0.5  0.27  0.381   0.153
```

| 指标 | 通俗解释 |
|---|---|
| **P（精确率）** | 报出来的框里，有多少是真的。报警器：宁可不报也别乱报 → 看这个 |
| **R（召回率）** | 真实的框里，找到了多少。宁可错杀不可放过 → 看这个 |
| **mAP50** | 综合分，够用就行；0.5 以上可用，0.7 以上不错 |
| **mAP50-95** | 更严格，看框贴得准不准 |

## 6. 训练完看什么

```
runs/school_v4/
├── weights/
│   ├── best.pt     ← 用这个
│   └── last.pt     ← 最后一轮（可能已经崩了，别用）
├── results.csv     ← 每个 epoch 的指标
├── results.png     ← 曲线图，先看这张
├── confusion_matrix.png   ← 混淆矩阵，看误检/漏检谁多
├── train_batch*.jpg       ← 训练时的真值框（检查标注有没有错）
└── val_batch*_pred.jpg    ← 验证集的预测效果（最直观）
```

**判断标准（按顺序看）**：

1. `val_batch*_pred.jpg` —— 框得像不像，一目了然。
2. `results.png` —— 曲线是正常下降，还是崩了。
3. `confusion_matrix.png` —— 背景被误判成自行车多不多。
4. 指标 —— 只是参考，3 张验证图上 mAP 波动 ±0.1，别太当真。

要判断过拟合/欠拟合，跑：

```bat
python relabel\diagnose_training.py --run runs\school_v4
```

## 7. 四个常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| `mAP50 = 0` 全程不动 | 只训 1 类但标签有 2 类；或坐标没归一化 | 先跑 `check_dataset.py` |
| loss 突然跳到 3.5+，mAP 归零 | 学习率太大 / 数据太少 | `--lr0 0.001`，`--imgsz` 降一档 |
| `CUDA out of memory` | batch 或 imgsz 太大 | `--batch 4` 或 `--imgsz 960` |
| 每轮几十秒，慢得离谱 | 没开 AMP / 图片没缩放 | 加 `--amp`；大图先缩到 1600px |

## 10. 给你的练习（30 分钟）

1. 跑一次 `check_dataset.py`，看懂输出。
2. 用 `--epochs 30` 训一版，全程盯着 loss 和 mAP。
3. 训练完打开 `runs/xxx/val_batch0_pred.jpg`，看框准不准。
4. 跑 `diagnose_training.py`，读它给的判定。
5. 故意把 `--lr0` 改成 0.05 再训一次，亲眼看看"发散"长什么样——这是最值钱的一课。
