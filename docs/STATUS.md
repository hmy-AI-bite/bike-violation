## 三、判定原理（核心结论）

**"越界"不是模型学出来的，是几何算出来的。**

```
YOLO 检测框 → SAM2 掩膜 → 掩膜最低 2% 的"接地点" → 与标定多边形比 → 合规/压线/出界/占道
```

用框判定 vs 用掩膜判定（同一批 17 张、同一区域）：

| 规则 | 判违停 | 差异 |
|---|---|---|
| 框规则 | 72 辆 | 框含背景，斜靠车误报 |
| 掩膜规则 | 32 辆 | **少 40 处误报（-56%）** |

最新一次（用户重画区域后）：合规 236 / 压线 13 / 出界 13，共 26 辆。
由于这 17 张**全部是规范停放**，这 26 辆即为误报，**误报率约 10%**，主因是区域与白线不重合。

## 四、区域：整个系统的瓶颈

| 手段 | 精度 | 成本 |
|---|---|---|
| 固定机位标定一次 | 100% | 每摄像头 1 次 |
| 单应迁移（跨角度） | 90~95% | 需参考图 + 可能失败 |
| 迁移 + 白线吸附 | ~95% | 依赖白线可见 |
| 模型自动识别区域 | 未知 | 需 200~500 张多边形标注（现有 17） |

实测：单应本身很稳（全特征 vs 仅地面特征，角点差 0.4%），但**迁移误差仍达 5~10% 图宽**；吸附能把框拉回白线。

## 六、已知限制

1. **区域必须人给**：单帧图像无法唯一推出"哪里允许停车"。
2. **没有违停正样本**：17 张全是规范停放，召回率无数据支撑（误报率可测，约 10%）。
3. **`parking_area` 学不会**：17 张里只有 14 个样本，2 类检测中该类 mAP = 0。
4. **COCO 模型的四个毛病**：一辆车碎成多框、密集车群切碎、分不清实体与海报、分不清影子。前两个靠重标解决，后两个只能加负样本。
5. **SAM2 会粘车**：重度重叠可能抠成一体。
