# 图片判定规则修复（2026-11-22）

## 行为变化

- 框规则和掩膜规则均从模型 names 中查找 bicycle；兼容 COCO 类别 1 和微调类别 0。模型没有唯一 bicycle 类时立即报错。
- 修复掩膜流水线中 RGB 数组被 YOLO 当作 BGR 读取的问题；YOLO 收到 BGR，SAM 收到 RGB，使用同一尺寸和坐标。
- 图片区域配置只在缺少键时继承场景默认值。显式 allow: [] 表示未标定；deny: [] 表示没有禁停区。
- 注意旧配置中预先创建的空 allow 条目现在也表示未标定。若希望继承场景默认区域，应删除该图片条目的 allow 键；不要批量覆盖原始标定。
- 接地点近似取目标掩膜高度的最低 2%（向上取整，至少两行），不再取整张图高度的 2%。可用 --contact-ratio 调整。
- 面积不足或质量检查失败的掩膜记录为“无法判定”，保留 CSV 行和 reason，不计入合规或违停。灰框显示待复核目标。
- --min-mask-area 默认 200（缩放后像素数，保留原阈值）；--min-mask-score 默认 0，仅排除非有限分数，可按验证集结果提高。SAM 分数不是违停概率。
- 没有允许区域时只检测并输出“未标定”，不执行 SAM 编码和分割。
- 每次成功运行都重写 per_bike.csv，即使零检测也写表头，避免残留上次结果。CSV 原字段保留，新增 reason；无法计算的比例使用 -1。
- 输出的两套规则报警数量只表示差异，不再称为误报。框规则计数包含全部已标定检测框，掩膜计数只包含可判定目标。

## 保留的判定阈值

1. 车身掩膜与禁停区重叠比例 > --deny-tol（默认 0.05）：占道。
2. 接地点条带落在允许区内的比例 >= 0.9：合规。
3. 比例 > 0.1 且 < 0.9：压线。
4. 比例 <= 0.1：出界。

这些仍是二维图像规则。最低条带不等于真实车轮接地点，车身掩膜投影也不等于地面占用；遮挡、粘车和区域误差仍需真实标注评估。没有依据调整 0.1/0.9/0.05 阈值，也不宣称准确率提升。

## 训练入口

train.py 默认 lr0=0.002、workers=0、AMP 开启；--amp 保持可用，--no-amp 显式关闭。训练与验证轮末检查损失/指标的 NaN/Inf 并报错，不能修复数值异常的根因。验证轮末回调发生在框架保存之后，报错轮的权重仍可能存在，不应据此认定其有效。优化器仍沿用框架默认 auto，实际学习率以训练日志为准。

三个训练/判定入口的项目内默认路径改为相对脚本定位。外部 SAM 仓库仍复用原安装路径；--sam-checkpoint、--sam-config、--sam-device、--device 可覆盖运行配置。数据 YAML、其他脚本和启动器未做全项目路径迁移。
